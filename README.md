# المهندسة غيداء وهيب محمد الدبعي | Eng. Ghayda Waheeb Al-Dubei

مهندسة تقنية معلومات (IT Engineer) ومطورة برمجيات شغوفة ومتميزة. أمتلك خلفية أكاديمية قوية وخبرة عملية متقدمة في هندسة وبناء الأنظمة البرمجية المتكاملة، وتحليل متمتطلبات سوق العمل التقني بدقة. 

متخصصة بشكل محترف في تطوير تطبيقات الهواتف الذكية (Mobile Application Development) باستخدام إطار العمل فلاتر ولغة دارت (**Flutter & Dart**)، مع التركيز على بناء واجهات مستخدم سلسة، جذابة، وتفاعلية تعتمد على أفضل معايير تجربة المستخدم الرقمية (**UI/UX Design** والهوية البصرية).

من أبرز أعمالي الهندسية تطوير نظام **Trainex**، وهو نظام متكامل لإدارة وأتمتة التدريب الميداني (**Field Training Management System - FTMS**)، والذي صُمم لربط الجوانب الأكاديمية بالعملية بشكل ذكي ومنظم. أسعى دائماً لتوظيف الحلول التقنية الحديثة لابتكار برمجيات تخدم المجتمع وتسهل الأعمال اليومية بكفاءة عالية.
